# 🦷 Nha Khoa Thu Mảnh — Dental Clinic Web Application

Website giới thiệu dịch vụ và đặt lịch khám trực tuyến cho **Nha Khoa Thu Mảnh** (Số 11, Đường số 20, khu phố Hưng Thịnh, Đồng Nai — Mở cửa 24/7).

---

## 🚀 Khởi Chạy Nhanh (Quick Start)

```bash
# 1. Cài đặt dependencies
npm install

# 2. Chạy môi trường phát triển (http://localhost:3000)
npm run dev

# 3. Kiểm tra kiểu dữ liệu TypeScript
npx tsc --noEmit

# 4. Build bản production
npm run build
```

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend:** Next.js 16.2 (App Router), React 19, TypeScript 5
- **Styling & UI:** Tailwind CSS v4, `shadcn/ui`, Lucide Icons, Framer Motion
- **Form & Validation:** React Hook Form v7 + Zod v4
- **State & Data:** TanStack Query v5 + Zustand v5
- **Backend (Planned):** C# ASP.NET Core 9 Web API + Entity Framework Core 9
